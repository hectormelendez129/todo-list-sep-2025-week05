## Project Overview

A simple, responsive To-Do List web application built with HTML, CSS, and JavaScript.
This app allows users to easily create, edit, mark complete, and delete tasks in an intuitive interface helping boost productivity and task management.

## Features

- Add New Tasks by clicking New Task to create a new item instantly.
- Mark Complete, check the box to mark a task as complete (locks the text and strikes through).
- Delete any item by clicking the trash icon.
- Edit tasks directly in the textarea when they’re not marked complete.
- Task data is stored dynamically in memory during a session.
- Adapts to desktop and mobile screen sizes.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/<username>/todo-list-sep-2025-week05.git
````

2. Navigate to the project directory:

```bash
cd todo-list-sep-2025-week05
```

3. Open index.html in your browser

## Usage
1. Open index.html in a browser.
2. Click “New Task” (pencil icon) to create a new item.
3. Type your task into the textarea.
4. Check the box to mark the task as complete (locks editing).
5. Click the trash icon to delete the task.
6. Repeat as needed.
